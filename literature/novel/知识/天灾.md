
# 索林原虫
来自银河外的**生物虫群**
吞噬与同化：舰队由生物个体构成。占领星球后将其“腐化”为孵化场，不断生产新舰队。拥有极高的护甲，使用生物导弹和舰载机。在占领一定星域后，宿敌“哨兵”文明会前来援助银河。

# 高维恶魔
来自其他维度的入侵者，寻求在现实宇宙立足。
维度入侵：通过“恶魔引擎”和“维度锚”建立入侵据点。其存在依赖“形态完整度”，需要恶魔引擎维持，但因此也获得了强大的产能减免。入侵后期，恶魔内部不同派系（如背道者、狂热者）会同时出现并互相交战。
# 肃正协议
上古文明创造的失控AI，旨在通过灭绝所有有机生命来防止宇宙级灾难“三十级奇点”。
精准净化：激活后释放覆盖全银河的“幽灵信号”，干扰并控制合成人。舰队装备射程极远、威力巨大的粒子光矛。在银河系藏有多个机械世界作为中枢，必须全部摧毁。部分机械堕落帝国有可能觉醒为“最终防御协议”帮助对抗它。
# 玩家降临
指游戏玩家本身或其控制的帝国被视为一种天灾。
无法预测与极致优化：玩家具备超乎游戏内AI的战略谋划、极限运营和科技爆炸能力。行为无法用常规逻辑预测，可能采用各种“骚操作”和“黑科技”套路。其扩张和胜利欲望本身就是对银河系固有秩序的终极冲击。
